Configuración inicial

Esto se hace una sola vez en este celular/PC.

Necesitás la URL de la aplicación web de Google Apps Script conectada a la planilla de stock. La obtenés desde la hoja: Extensiones → Apps Script → Implementar → Administrar implementaciones. Pegá acá la URL que termina en /exec. Si ya configuraste la app de Reportes en este mismo teléfono, se usa la misma URL automáticamente.
